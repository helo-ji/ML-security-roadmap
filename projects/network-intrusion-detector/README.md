# ML-Powered Network Intrusion Detector

A small machine learning and cybersecurity project that classifies labelled network-traffic records and generates a report of potentially suspicious activity.

## Project Goals

- Learn how machine learning can support network intrusion detection.
- Practise data preparation, classification and model evaluation.
- Understand false positives, false negatives, precision, recall and F1-score.
- Generate a report that can support security alert triage.
- Introduce automated testing and CI using GitHub Actions.
- Build an interactive dashboard as a later enhancement.

## Planned Features

1. Load and inspect a labelled network-traffic dataset.
2. Train and evaluate a baseline classification model.
3. Predict whether traffic records are normal or suspicious.
4. Export predictions to a CSV report.
5. Add automated tests and a CI workflow.
6. Develop a user-friendly dashboard.

## Technology Stack

- Python
- Pandas
- scikit-learn
- Git and GitHub
- GitHub Actions
- Streamlit (planned dashboard)
